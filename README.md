# einzig1000.github.io

横山 允信（ヨコヤマ タダノブ）のポートフォリオサイトです。

- 公開URL: https://einzig1000.github.io/
- 構成: 素の HTML / CSS / JavaScript（ビルド不要）

```
index.html      … ページ本体
css/style.css   … スタイル（ライト／ダーク対応）
css/dig.css     … ページを地層にして掘り進める演出のスタイル
js/main.js      … スクリーンショットの拡大表示
js/dig.js       … 各セクションを層として重ね、クリック・ドラッグで掘って下の層へ進む演出（「普通に読む」で通常表示）
images/         … 作品画像
```
