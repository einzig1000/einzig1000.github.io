MyCraftBuilders

“採掘”にフォーカスしたボクセルゲーム（自作エンジン NobleEngine で開発）

制作開始
3年次 4月（2026.04〜 制作中）
制作人数
1人
開発環境
C++・HLSL ／ 自作エンジン NobleEngine（DirectX12）
担当箇所
すべて
GitHub リポジトリ（NobleEngine）→

2年次に作った初代 “MyCraftBuilders” を、「採掘の気持ちよさ」に絞ってリメイクしている作品です。 現在は、持っているアイテムを振るとその軌跡に沿ってブロックがえぐり取れるリアルタイム採掘と、 指定範囲を一撃で破壊する範囲採掘の2パターンを実装しています。 今後は爆薬による大量破壊や、魔法による地形編集も追加していく予定です。

“採掘の面白さ”を分解する

手応え

たくさん採掘音を出す

手応えの内訳は「音7割・パーティクル2割・その他1割」。採掘音は延々聞けても、採掘映像は延々見られない。一撃で大量に掘ったときは音が重なった方が満足感が違います。

景色

自由に採掘できるようにする

掘り終わったあとに「やってやった感」が残る景観に。水平に掘る、球状に掘るなど、掘り方の選択肢が多いほど景色が整います。

一撃破壊

視界内でたくさん破壊する

広範囲を掘れる代わりにデメリットもある。そのデメリットを踏み倒せるほど成長し、大量破壊を連発できた瞬間が本当のカタルシスだと考えています。

初代 MyCraftBuilders は3つとも満たせていなかった。そこで──

ブロックを、超ちっちゃくする。

ブロックのサイズ

2.0f → 0.1f

ブロック描画面数

4,064,256 → 737,280,000

  • 1回のスイングで大量に掘れても違和感がない → 音・パーティクルをたくさん出せる
  • 細かく掘れる → 採掘の自由度が上がり、地形を好きに整えられる
  • 同じ距離を掘っても一撃の採掘量が桁違い → 大量破壊のカタルシスが上がる

描画面数を増やすための描画パイプラインの変遷

そのままの設計では到底描画できない面数になったため、ブロック描画のシェーダーをバージョン管理しながら段階的に作り替えました。 最終的に Compute Shader で露出面を焼き込み → Amplification Shader で間引き → Mesh Shader で描画 する GPU 主導の構成になっています。

  1. v1.0

    立方体モデルをインスタンシング描画

  2. v2.0

    Mesh Shader を導入。CPUで作ったメッシュをチャンク単位で描画し、DrawCall を大幅に削減

  3. v2.1

    ブロック配列を Mesh Shader に渡し、GPU 上でメッシュを生成（CPU 側のメッシュ生成が不要に）

  4. v2.2

    露出している面だけを生成するようにして描画頂点数を削減

  5. v3.0

    毎フレームだった面生成を Compute Shader に移し、チャンク更新時のみ実行 GPU FPS 130

  6. v4.0

    Amplification Shader を導入し、面を持たないグループを描画しない GPU FPS 190

  7. v4.1

    グループ単位の視錐台カリングを追加 GPU FPS 170〜220

GPU FPS はシェーダー更新時に記録した自己計測値です（RTX 4060 Laptop）。

そのほかの実装

  • 採掘ポイント → 経験値オーブ → 採掘レベルの成長サイクルと、レベルを使ったツールのアップグレード
  • ブロック破壊時のパーティクルと、イベントバスを使ったエフェクトの実装パターン
  • スケルトンを持たないモデルにも対応したアニメーションシステム
  • 3Dモデルからアイテムアイコンを自動生成するアイコンシステム
  • ImGui による各種エディタ
  • GitHub Actions によるビルドチェック
